Windows PC

Microsoft Family Safety covers Windows, Xbox and Edge from one dashboard.

DeviceAbout 15 minutesSource confidence: highChecked 20 August 2026

What to watch for

  • Web filtering only works in Microsoft Edge, so other browsers need blocking
  • A local (non-Microsoft) account bypasses everything
  • Game downloads and in-game spending

Before you start

  • Your child needs their own child Microsoft account, signed in on the PC. If they use your account, none of this applies.
  • Web filtering is Edge-only. Plan to block other browsers, or the filter does nothing.
  1. 1

    Create a child account in your family group

    The foundation for everything else.

    family.microsoft.com

    1. Go to family.microsoft.com and sign in with your Microsoft account.
    2. Add a family member, choosing the child option, with their correct date of birth.
    3. On the PC, sign them in with that account and make sure they’re not using yours.
  2. 2

    Set content filters

    Blocks adult sites in Edge and sets age ratings for apps and games.

    family.microsoft.com → [your child] → Content filters

    1. Turn on Filter inappropriate websites and searches.
    2. Turn on Only use allowed browsers, which blocks Chrome, Firefox and others.
    3. Under Apps and games, set the age rating limit.
    Recommended by age
    7–11Age rating 7, allowed sites only
    11–12Age rating 12, adult sites blocked
    13–15Age rating 12–16, adult sites blocked
    16–17Age rating 16–18, adult sites blocked
  3. 3

    Set screen time

    You can set different limits per device, which helps if homework happens on the same PC.

    family.microsoft.com → [your child] → Screen time

    1. Set a schedule for the Windows device.
    2. Add separate app limits if a specific game is the problem rather than the PC itself.
  4. 4

    Require approval for purchases

    Stops surprise Microsoft Store and game purchases.

    family.microsoft.com → [your child] → Spending

    1. Turn on 'Needs organizer approval to buy things'.
    2. Turn on email notifications for purchases.
    3. Remove any saved card, or use a balance instead.
  5. 5

    Turn on activity reporting

    A weekly summary is a better conversation starter than a live feed.

    family.microsoft.com → [your child] → Activity reporting

    1. Turn on activity reporting and weekly email summaries.
    2. Tell your child it’s on. Reports work better as a shared thing.

Safety check

  • Child Microsoft account created and in use
  • Web filtering on, other browsers blocked
  • App and game age ratings set
  • Screen time schedule set
  • Purchases need approval
  • Activity reporting on

Worth talking about

  • Agree homework time versus game time rather than one blanket limit.
  • Explain that the web filter only works in Edge, so switching browsers isn’t a loophole, it’s just blocked.
  • Look at the weekly report together.
